# Progress docs

`ROADMAP.md` is the one-page summary (stage, headline parity numbers, estimates). Under it:

| Doc                          | Holds                                                              |
|------------------------------|--------------------------------------------------------------------|
| `docs/target-app-parity.md`  | The assessment: readiness per audience, per dimension              |
| `docs/gaps.md`               | The work list; pick work from its top rows                         |
| `docs/roadmap.md`            | Milestones and their gates                                         |
| `docs/ui-parity.md`          | UI element by element against Autodesk AutoCAD 2026 (Windows)      |
| `docs/geometry-parity.md`, `docs/file-format-parity.md`, `docs/hardware-parity.md`, `docs/localization-parity.md` | Deep checklists |
| `docs/parity-checklist.md`   | Generated by `cargo xtask parity`; never hand-edit                 |

Every doc starts with a status line:
`> **Last reviewed:** YYYY-MM-DD · **Last updated:** YYYY-MM-DD · **Change:** minor|major (what) · **Target:** Autodesk AutoCAD 2026 (Windows)`
and ends with a revision-history table (Date | Change | Summary).

When work lands: update the affected rows, the status line and the revision history in the same
commit. Numbers are either **measured** (counted from code or from a side-by-side comparison) or
**estimated**, and each says which.
